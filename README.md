# Калькулятор дверей-купе

Статическое HTML-приложение, работает оффлайн с любого носителя (USB / папка на диске).

### Обновление 2.11 — 30.09.2026

В ширине и высоте проёма можно вводить суммы: `808+880` → `1688` мм.
Enter, выход из поля или «Рассчитать стоимость» заменяют выражение итоговым числом.
Поддерживаются несколько слагаемых, пробелы вокруг `+`, дробные числа с точкой или запятой.
Во время набора выражение не заменяется и курсор не перескакивает.
Диапазоны проверяются по сумме: ширина 400–6000 мм, высота 600–3000 мм.
Незавершённые/ошибочные выражения отмечаются у поля. Умножение, вычитание и скобки не поддерживаются.
Предупреждение о выходе за каталоговые пределы отдельной двери остаётся при явном расчёте,
но больше не блокирует живой ввод и смену количества дверей.

Проверка парсера: `node tests/dimension-sums.test.cjs`.

## Запуск (для менеджера)

1. Распаковать архив `kupe-vX.Y-YYYY-MM-DD.zip` в любую папку — например, `C:\Калькулятор купе\`.
2. Зайти в папку, **двойной клик по `index.html`** — откроется в браузере по умолчанию.
3. Готово, можно работать. Интернет **не нужен**.

### Если что-то идёт не так

- **Браузер показывает «пустую» страницу или ругается на скрипты:** нажми `Ctrl + Shift + R` (жёсткая перезагрузка). Если не помогло — открой папку и кликни `index.html` правой кнопкой → «Открыть с помощью» → выбери Chrome или Edge.
- **Сохранённые расчёты пропали:** черновики лежат в кэше браузера на этом компьютере. Чистка кэша / другой браузер / другой пользователь Windows = их не видно. Это нормально для текущей версии.
- **Цифры в КП кажутся неверными:** проверь версию прайса (видна в верхней строке окна: `v 2.5 — ДАТА`). Если дата старая — сообщи разработчику.
- **Печать едет / пустые страницы:** в окне печати убедись, что выбран формат **А4**, поля «По умолчанию» или «Узкие», масштаб «По размеру страницы».

## Что умеет

- Расчёт стоимости купе по введённым параметрам (размер проёма, кол-во дверей, профиль, наполнение).
- Визуализация дверей с секциями.
- Авто-наценки: профиль ×3, плёнка по типу наполнения, сложная сборка от 4 секций на дверь.
- Сохранение проектов на этом компьютере (кнопка «Сохранить»).
- Загрузка ранее сохранённых проектов (кнопка «Открыть»).
- Печать / сохранение КП в PDF.

## Структура (для разработчика)

```
projects/kupe/
├── index.html          ← одна страница, входная точка
├── css/main.css        ← все стили
├── data/
│   ├── fillings.js     ← каталог наполнений (зеркала, стекло, лакобель, ЛДСП, плёнки…)
│   └── profiles.js     ← системы профилей купе и цвета
├── js/
│   ├── utils.js
│   ├── store.js        ← AppState + EventBus
│   ├── router.js       ← одна вкладка, но роутер оставлен для совместимости
│   ├── shared-kp.js    ← КП-модал (open/close/print)
│   └── kupe.js         ← вся бизнес-логика модуля
├── tests/
│   └── manual.md       ← контрольные сценарии QA (заполняется перед релизом)
├── README.md           ← этот файл
└── TODO.md             ← баги, не блокирующие релиз
```

### Шрифт

Используется системный (`Segoe UI` / `Helvetica Neue` / `Arial`). Fontshare CDN отключён, чтобы приложение не зависело от интернета.

### Обновление прайса

1. Открыть `data/fillings.js` или `data/profiles.js` в любом текстовом редакторе.
2. Изменить нужные значения (поле `p` для цен).
3. Обновить `*_VERSION` в начале файла (формат `YYYY.MM.DD`).
4. Сохранить, открыть `index.html` заново → новые цены применяются.
